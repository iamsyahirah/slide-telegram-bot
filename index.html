PART 1 — CREATE THE TELEGRAM BOT · Steps 1–2

Talk to BotFather

Every Telegram bot is created through one official account. No dashboard, no signup form — just a chat.

STEP 01
Open Telegram
Open the Telegram app on your phone and search for @BotFather. Make sure you select the official BotFather account.
STEP 02
Create a new bot
Send the command below. BotFather will ask what to call your bot — enter any name you like, e.g. ESP32 Temperature Alert.
You/newbot
BotFatherAlright, a new bot. How are we going to call it?

Username & Bot Token

PART 2 — START YOUR BOT · Step 5

Open the conversation

A bot can't message you first. This one handshake is what unlocks everything after it.

WHY THIS MATTERS
BotFather gives you a link to your new bot. Open it, then press START — or simply send /start. Your bot needs a conversation with you before you can retrieve your Chat ID in the next part.

PART 3 — GET YOUR CHAT ID · Steps 6–7

Two IDs your ESP32 needs

You already have the bot token. Now extract the Chat ID from Telegram's own API.

STEP 06
Message your bot
Send anything simple — e.g. hello.
STEP 07
Call getUpdates
Open a browser and visit the URL on the right, replacing YOUR_BOT_TOKEN with your real token. This method retrieves incoming messages received by your bot.
browser
https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
response
"chat":{
    "id":123456789,
    "first_name":"Shikin"
}

PART 5 — TEST TELEGRAM WITH ESP32

One message, before any sensors

Before wiring up DHT11, a buzzer, or an LED — confirm the ESP32 can send a single Telegram message.

sketch.ino
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <UniversalTelegramBot.h>

// WiFi
const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_WIFI_PASSWORD";

// Telegram
#define BOTtoken "YOUR_BOT_TOKEN"
#define CHAT_ID "YOUR_CHAT_ID"

WiFiClientSecure client;
UniversalTelegramBot bot(BOTtoken, client);

void setup() {
  Serial.begin(115200);
  client.setInsecure();          // allow secure Telegram connection
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }

  bot.sendMessage(CHAT_ID, "ESP32 is connected!", "");
}

void loop() {}

PART 10 — ADD YOUR TEMPERATURE ALERT

From test message to real alert

Once the basic test works, connect the same sendMessage() call to your DHT11 sensor.

sketch.ino
if (temperature >= 31.0) {
  bot.sendMessage(
    CHAT_ID,
    "⚠️ HIGH TEMPERATURE ALERT!\nTemperature is above 31°C.",
    ""
  );
}
